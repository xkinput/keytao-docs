# 承载键道

得益于强大的 RIME 开源输入平台,用户可以在不同的操作系统中使用键道。

本章节将指导你完成键道输入方案的获取、更新和卸载操作。无论你使用的是 Windows、macOS 还是其他操作系统,都能在这里找到对应的安装指南。

## 章节内容

- **[获取键道](./download-and-install)** - 下载并安装键道输入方案
- **[更新键道](./update)** - 更新 Rime、键道与码表
- **[卸载键道](./uninstall)** - 彻底移除键道及所有配置

::: tip 提示
安装前请确保你已经了解了键道的基本概念,可以先阅读[星空键道简介](/guide/)。
:::
