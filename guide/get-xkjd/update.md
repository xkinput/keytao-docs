# 更新键道

运行 **[KeyTao 键道安装更新程序](https://github.com/xkinput/keytao-installer/releases/latest)** 即可一键完成键道方案的更新，支持 Windows / macOS / Linux / Android。

## iOS

iOS 平台暂不支持安装更新程序，请通过以下方式手动更新：

- **[元书输入法](https://apps.apple.com/app/id6744464701)（推荐）**：进入「输入方案 → 下载方案」，填写最新 `keytao-ios-*.zip` 的下载链接重新下载，然后「方案目录切换，选择键道目录 → 打开 → 部署」即可
