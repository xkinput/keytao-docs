# 喵喵机器人使用流程

喵喵是键道社区的词库助手。它可以帮你查词、算编码、写草稿、提交审核，也会在提交后先做一轮自动审词。喵喵不会绕过词库审核系统直接乱改词库；所有修改都会进入你的键道账号草稿或审核批次，并留下批次链接与审核记录。

## 使用前先绑定账号

需要修改词库时，喵喵必须知道你对应的键道网站账号。

1. 登录 [键道网站](https://keytao.vercel.app)。
2. 进入右上角用户菜单中的“我的资料”。
3. 在“机器人账号绑定”区域点击“生成绑定码”。
4. 绑定码有效期为 10 分钟，且只能使用一次。
5. 回到 QQ 或 Telegram，发送：

```text
/bind 绑定码
```

例如：

```text
/bind 26PZWH
```

绑定成功后，你在群里或私聊中通过喵喵创建的草稿，都会归属到这个键道账号下。

::: tip
群聊里建议使用 `@喵喵`，或以“喵喵”“键道”开头。私聊中可以直接发送。
:::

## 基本工作逻辑

喵喵处理词库修改时通常会走这条链路：

1. 理解你的请求，确认你要查词、加词、改词、删词还是调整顺序。
2. 查询当前词库、编码链和同码词位置。
3. 对新词或改码词进行读音与编码检查。
4. 把修改写入你的草稿批次，并展示 diff、草稿条目和批次链接。
5. 你回复“提交”后，喵喵先自动审词。
6. 证据充分且规则明确时，本喵会自动审核通过；否则进入管理员审核。
7. 已通过的批次会等待 GitHub 词库同步发布。

草稿链接形如：

```text
https://keytao.vercel.app/batch/批次ID
```

## 查词与问编码

你可以直接问：

```text
喵喵 直播间
喵喵 直连 直链
喵喵 这个编码 fbjui 是什么词
喵喵 偶极子怎么拆
```

喵喵会优先调用词库和编码工具，不会只凭记忆猜编码。若你引用了喵喵的一条消息再问“这两个词现在词库都有吗”，喵喵会以被引用消息中的词为准；如果平台没有把引用原文传给喵喵，它会说明原因并请你直接发词。

## 加词

最简单的加词方式是直接发送词：

```text
喵喵 安泊
```

如果词库尚未收录，喵喵会：

- 查找权威来源或常见用法信号，确认读音与词义。
- 调用键道编码规则生成候选编码。
- 展示当前可加的位置、已有占用词、推荐编码和来源。
- 等你确认后写入草稿。

你可以回复：

```text
喵喵加
1
2
都加
```

含义分别是：

| 回复 | 含义 |
| --- | --- |
| `喵喵加` / `确认` / `好` | 使用喵喵推荐编码加入草稿 |
| `1` / `2` | 选择候选列表中的第几个编码 |
| `都加` | 对多读音、多候选场景，加入每个读音的推荐编码 |
| `编号 重新编码` | 选择某个已占用编码，并让喵喵尝试把原词顺延到它自己的下一个合理编码 |

::: warning
如果你跳过更短的空位，直接把词加到更长编码，例如前面的 `fmzla` 仍为空却要加到 `fmzlai`，喵喵会先警告并要求你确认。一般不建议跳过编码链中的空位。
:::

## 改词与改编码

你可以要求替换词条内容：

```text
喵喵 把 质保金 改成 直播间
```

也可以要求调整编码：

```text
喵喵 把 直播间 调到 fbjui
喵喵 把 质保金 挪到 fbjuio
```

喵喵会检查：

- 原词是否真的在词库中。
- 新词是否更适合该编码。
- 新编码是否在该词的键道候选编码链内。
- 如果是声笔笔短码表（`CSS` / `CSSSingle`），会按短码表事实与优先级审查，而不是用普通词组双拼规则误判。
- 如果涉及同码链调序，会比较日常使用场景、词典、百科、搜索与语料信号。

如果证据显示调整合理，提交后可能由本喵自动审核通过。若常用度证据不足、存在歧义，或调整动机不清楚，则会等待管理员审核。

## 删除词条

删除可以这样说：

```text
喵喵 删除 旧词
喵喵 把 旧词 从 abc 删除
```

删除会先进入草稿和审核流程。纯删除不会由喵喵自动通过，必须等待管理员确认。

::: tip
如果你其实是把一个词从旧编码移动到新编码，可以说“把某词从 A 调到 B”。这种“删旧位 + 加新位”的改码操作，若编码和证据都正确，可以由喵喵自动审核。
:::

## 调整同码词顺序

键道词库中，同一个编码下可能有多个词。更常用、更适合日常输入的词应该排在更前面。

你可以说：

```text
喵喵 把 直播间 调到 质保金 前面
喵喵 直播间 应该比 质保金 更常用，帮我调序
```

喵喵会检查：

- 两个词是否都存在。
- 它们是否处在同一编码链或相关编码位置。
- 调整后是否符合日常使用优先级。
- 是否有足够的搜索、词典、百科、语料或专业常识支持。

如果优先级不明显，喵喵会提示“同码链优先级确认”，需要你确认一次才会提交。提交后若证据仍不足，会交给管理员审核。

## 草稿管理

常用草稿命令：

```text
喵喵 查看草稿
喵喵 删除草稿里的第 2 条
喵喵 只保留 直播间
喵喵 撤回刚刚提交的批次
喵喵 提交
```

说明：

- “查看草稿”会展示 diff、当前草稿条目和草稿链接。
- “删除草稿里的第 N 条”只删除草稿项，不会直接改正式词库。
- “只保留某词”会删除草稿里其它项，适合一批操作后只留下需要的一条。
- “撤回”只能撤回还在审核中的最近批次；如果你已经有新的草稿内容，可能无法撤回旧批次。
- “提交”会把当前草稿提交审核；提交后不要继续让喵喵查看草稿，否则会新建空草稿。

## 自动审核规则

喵喵提交后会先做自动审词。自动通过需要满足“证据一致、编码正确、动机清楚”。

通常可以自动通过的情况：

- 新增常见词，读音与编码一致，来源或常识信号明确。
- 改编码时，新编码在键道候选编码链内。
- 把词从错误位置移动到更合理的位置，且新旧变化清楚。
- 调序时，前置词明显更常用，且证据一致。
- 常见大众词虽然未必每次都有权威词典条目，但读音、含义和用法高度明确。

通常会等待管理员审核的情况：

- 纯删除。
- 读音来源冲突或多音歧义未解决。
- 编码不在键道候选链中。
- 调序理由不充分。
- 同码链里哪个词更常用并不明显。
- 词义、语域、专业领域存在争议。

喵喵会在批次中写入审核记录，管理员审核页也会展示喵喵的审查意见。没有喵喵备注的批次，管理员也可以手动触发喵喵复查。

## 权限与群聊安全

每个人只能确认自己的待确认操作。群聊中如果你引用了别人触发的加词确认，喵喵会提醒你不能替别人确认；若你确实想加同一个词，可以让喵喵复制到你自己的草稿后再确认。

这条规则用于避免群里误操作，也避免把别人的草稿提交到你的账号里。

## GitHub 同步与发布

自动审核或管理员审核通过后，批次会进入“待同步 GitHub”状态。喵喵会定期检查是否需要发布词库更新。

默认发布节奏：

- 每周三、周日 10:00 检查一次待同步批次数量。
- 默认阈值为 10 个批次；待同步批次数量超过 10 个时自动触发同步。
- 同步时会创建 GitHub PR。
- PR 会由系统自动合并。
- 合并后会基于最新 Release 版本号自动打下一个 patch tag，并发布 GitHub Release。
- 发布完成后，喵喵会在配置的群里通知同步 PR、Release 和待同步批次数量。

群通知大致会包含：

```text
本喵已完成 GitHub 词库同步并发布。
同步 PR：...
Release：...
发布地址：...
请大家检查与更新。
本次触发时待同步批次：N 个。
```

收到发布通知后，用户即可按自己的平台方式更新键道词库。
