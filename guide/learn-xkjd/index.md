# 研习键道

> 大道三千,键道为一。浩瀚星辰,无所畏惧。

在开始使用键道之前,你需要了解键道的基本原理和编码规则。本章节将带你深入理解键道的核心概念。

键道是一款音形码输入方案,结合了拼音(音码)和笔画(形码)两种编码方式。通过学习键道的键位布局、音码规则和形码规则,你将掌握键道的编码逻辑。

## 章节内容

- **[键道图谱](./layouts)** - 了解键道的键位布局和设计理念
- **[键道音码](./phonetics-rules)** - 学习双拼音码的编码规则
- **[键道形码](./stroke-rules)** - 掌握笔画形码的拆分方法

::: info 学习建议
建议按顺序学习本章节内容,先理解键位布局,再学习音码和形码规则。这将帮助你建立完整的键道知识体系。
:::
