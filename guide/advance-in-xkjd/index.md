# 融会键道

> 惜码如金,领会键道。

当你已经能够熟练使用键道输入单字和词组后,是时候学习键道的进阶技巧了。本章节将介绍键道的核心特性——简码、顶功和飞键。

这些高级功能是键道高效输入的关键所在。通过简码可以用更少的按键输入常用字词,通过顶功可以实现自动上屏,通过飞键可以获得更灵活的输入方式。掌握这些技巧,你的输入效率将得到质的飞跃。

## 章节内容

- **[简码](./shorthand)** - 学习简码的使用方法,提高常用字词的输入速度
- **[顶功(上屏)](./top-up)** - 理解顶功机制,实现流畅的连续输入
- **[飞键](./alt-code)** - 掌握飞键技巧,获得更多输入选择

::: warning 注意
进阶功能需要在熟练掌握基础输入后再学习。建议先完成入门章节的学习和练习。
:::
