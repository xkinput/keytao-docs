# 入门键道

> 音形结合,初窥键道。

掌握了键道的基本规则后,是时候开始实践了!本章节将教你如何使用键道输入单字和词组。

键道的编码规则看似复杂,但只要理解了音码和形码的组合方式,就能轻松上手。通过本章的学习,你将能够使用键道进行基本的文字输入。

## 章节内容

- **[单字](./characters)** - 学习单字的编码方法和输入技巧
- **[词组](./phrases)** - 掌握词组的编码规则和输入方式

::: tip 实践建议
理论学习固然重要,但实践才是掌握键道的关键。建议在学习过程中多加练习,从常用字词开始,逐步提高输入速度。
:::
